## 🔧 CRITICAL BUGS FIXED

### 1. **CORE ISSUE - Target Sequence Generation** (simple_latex_converter.py)
**Problem**: Model learning wrong input→output mappings:
- Was learning: <sos> → <sos> (wrong!)
- Should learn: <sos> → L → <eos>

**Fix**: Corrected target sequence generation:
```python
# Position 0: target is the actual symbol (next after <sos> input)
labels[0, 0] = self.vocab_dict[latex_string]
labels[0, 1] = 0  # Parent is root

# Position 1: target is end token (next after symbol input)  
labels[1, 0] = self.vocab_dict.get('<eos>', 0)
labels[1, 1] = 0  # Parent is root
```

### 2. **Decoder Input Bug** (models/Hierarchical_attention/decoder.py:103)
**Problem**: Using wrong tensor indices for word embeddings
```python
# OLD (WRONG):
word_embedding = self.embedding(labels[:, i, 3])  # Using relation tokens!

# NEW (CORRECT):
if i == 0:
    word_embedding = self.embedding(torch.ones(batch_size).long().to(device=self.device))
else:
    word_embedding = self.embedding(labels[:, i-1, 0])  # Use previous word token
```

### 3. **Loss Computation Bug** (models/Backbone_stroke.py:98)
**Problem**: Computing word loss against struct tokens instead of word tokens
```python
# OLD (WRONG):
word_average_loss = self.cross(
    word_probs.contiguous().view(-1, word_probs.shape[-1]), 
    labels[:, :, 1].view(-1)  # Using struct tokens!
)

# NEW (CORRECT):
word_average_loss = self.cross(
    word_probs.contiguous().view(-1, word_probs.shape[-1]), 
    labels[:, :, 0].view(-1)  # Using word tokens
)
```

### 4. **Accuracy Calculation Bug** (utils.py:136)
**Problem**: Comparing predictions against wrong label indices
```python
# OLD (WRONG):
word_label, struct_label = labels[:,:,1], labels[:,:,4:]

# NEW (CORRECT):
word_label, struct_label = labels[:,:,0], labels[:,:,4:]
```

### 5. **Tensor Indexing Bug** (decoder.py autoregressive inference)
**Problem**: Wrong tensor assignment syntax
```python
# OLD (WRONG):
word_probs[0][i, :] = word_prob

# NEW (CORRECT):
word_probs[0, i, :] = word_prob
```
